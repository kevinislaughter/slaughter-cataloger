Slaughter Cataloger :: Beta 2.7

User Guide

Overview

The Slaughter Cataloger is a browser-based bibliographic tool for cataloging periodicals. It works entirely offline — all data is stored in your browser and exported as CSV files for permanent storage.

  • Library — Manage title-level records (publishers, canonical titles, TitleIDs).
  • Issues — Record individual issue facts: volume, number, date, physical details. Requires a Titles CSV from Library.
  • Contents — Catalog the contents of each issue (articles, contributors, page ranges). Requires an Issues CSV.
  • Compiler — Generate checklists, full catalogs, RIS exports, and proofing sheets from your CSVs.

Workflow

  • 1. In Library, create title records and export a Titles CSV.
  • 2. In Issues, load your Titles CSV, select a title, and record issues. Export an Issues CSV regularly.
  • 3. In Contents, load your Issues CSV, select an issue, and record contents. Export a Contents CSV.
  • 4. In Compiler, load your Titles + Issues + Contents CSVs, select a title, and generate your output.

Data Persistence

All data is stored in your browser's localStorage. Export CSVs frequently for permanent storage. The Issues panel autosaves a CSV every 15 minutes when enabled. Session data restores automatically on reload.

Beta 2.7 session keys are separate from Beta 2.6 — your old session data will not auto-restore. Import your Beta 2.6 CSVs to migrate.

Key Identifiers

  • TitleID — TitleCode-FirstYear (e.g. GAZETTEKY-1895). Permanent; never changes.
  • IssueID — TitleID-KxxxxxxX (e.g. GAZETTEKY-1895-K7M4Q2). Generated on first Record. Permanent.

Field Conventions

  • ? (Speculative) — Mark a field when the value is inferred, uncertain, or from a secondary source. Resets after each Record.
  • N/A — Mark a field as not applicable for this record. Sticky across records.
  • Sticky fields — Some fields (Pages, Size, Price, Language, Country, Printer, Printer Location) carry forward to the next record after you hit Record.
  • Auto-advance — After recording, Volume/Issue/Whole No./Month/Year can auto-increment according to the Auto-advance checkboxes.

Compiler Output Types

  • Checklist — A numbered list of issues. Export as HTML, Markdown, or plain text.
  • Full Catalog — A styled HTML document (or WordPress blocks) with all issues and their contents.
  • Proofing Catalog — A printable PDF-ready document for checking records against physical issues.
  • RIS — Zotero-compatible bibliographic records for every contents item.

Cross-Panel Data Sharing

In Beta 2.7, the Slaughter Cataloger uses an internal SC state object to share data between panels. When you load a Titles CSV in Library and switch to Issues, Issues will offer to use the Library data. Similarly, Issues data flows to Contents and Compiler automatically when you switch panels.
